## Description

Profile Finder is a simple JavaScript project that allows users to search and filter profiles in real time. The application displays profile cards containing a person's image, name, and short biography. As the user types in the search bar, the profiles are filtered instantly without reloading the page.

The project is built using HTML, CSS, and JavaScript and focuses on practicing DOM manipulation, array methods, event handling, and dynamic content rendering.

---

## Features

* Real-time profile search
* Dynamic card generation using JavaScript
* Responsive card layout
* Profile image as card background
* Instant filtering while typing
* Modern and responsive user interface

## How It Works

1. User enters text in the search box.
2. The input event is triggered.
3. JavaScript filters the user data based on the search term.
4. Matching profiles are displayed dynamically.
5. Non-matching profiles are hidden automatically.
